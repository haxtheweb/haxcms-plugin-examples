# workshop-skeleton-pack (fake)

A made-up community skeleton pack with two starting points: a one-day workshop (core `clean-one` theme; enables `game-pack` and `comments`) and a workshop series (`neon-glow-theme` from the neon pack; enables `game-pack`). Declarative. Tests skeleton packs, `site.plugins`, and a skeleton depending on another pack's theme (listed in `suggests`; a missing theme falls back to the default theme with a warning).
