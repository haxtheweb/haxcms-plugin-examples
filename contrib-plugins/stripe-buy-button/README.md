# Stripe buy button (community element pack)

A block that sells a product or takes a donation with a [Stripe Buy Button](https://docs.stripe.com/payment-links/buy-button). Stripe hosts the checkout, so the site never handles card data, keeps no secret and runs no server code. Proposed in https://github.com/haxtheweb/issues/issues/2090.

- `stripe-checkout-block`: author sets the buy button ID (`buy_btn_…`) and publishable key (`pk_live_…` / `pk_test_…`) from the Stripe dashboard, plus an optional Payment Link (`https://buy.stripe.com/…`) and its link text.

How it behaves:

- The Payment Link renders first as a plain link, so the block still sells on static hosts, without JavaScript, in print and when the content is copied out of HAXcms.
- Stripe's script (`js.stripe.com/v3/buy-button.js`) loads only when the block nears the viewport, once per page, and never while the page is being edited.
- A secret or restricted key (`sk_` / `rk_`) is refused and never printed back into the page.

A pack (`kind: pack`, no backend code): turning it on adds the block to the site's block list. Off by default; payments are an owner's choice, never core. Element tests live in `test/` (web-test-runner).
