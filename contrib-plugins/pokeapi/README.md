# PokeAPI (community plugin)

Search Pokémon from the editor's appstore and insert them as interactive cards. Data comes from [PokeAPI](https://pokeapi.co/), a free, open API that needs no key.

## What authors get

- A **PokeAPI** app in the appstore. Search by name (`pika`, `mr mime`) or number (`25`); results show the official artwork.
- Picking a result inserts a `pokeapi-card` block. The card shows artwork, name, number, kind, types, HP and a line from the games. **Show stats** turns it over to base stats, abilities, height and weight. **Play cry** plays the Pokémon's call, and the card tilts toward a mouse pointer (not with reduced motion, and not for touch).
- The block is also in the block list, with settings for the Pokémon, which side to start on, and the language of the card's words (names, kind and game text come from PokeAPI in English, German, Spanish, French, Italian, Japanese, Korean and Chinese).

```html
<pokeapi-card pokemon="pikachu"></pokeapi-card>
<pokeapi-card pokemon="6" flipped lang="fr"></pokeapi-card>
```

## How it works

PokeAPI accepts only `limit` and `offset`, so it cannot search, and its list carries names but no images. The plugin reads the whole list once, keeps it in a `system` store shared by every site, and answers the appstore's searches itself (names starting with the search first, then names containing it, twenty to a page). PokeAPI's fair-use policy asks clients to cache, so the list is refreshed only when it is older than **Keep the Pokémon list for** (24 hours by default). If PokeAPI is down, searches keep using the stored list.

Cards load their data in the reader's browser, straight from PokeAPI, and keep it for the tab. They do not need this plugin's server: a card on a statically published site still works, and a card stays readable after the plugin is turned off. The data shaping lives once in `frontend/dist/pokeapi-data.js`, which the card and the Node entry both import (the PHP entry ports the search half).

## Settings

| Setting | Default | What it is for |
|---|---|---|
| PokeAPI address | `https://pokeapi.co/api/v2` | Change only for a self-hosted copy of PokeAPI |
| Mirror key | empty | Only for a mirror that asks for a key. Secret: stored on the server, never sent to browsers, and only sent to the mirror |
| Mirror key header | `x-api-key` | The header the mirror reads the key from |
| Keep the Pokémon list for (hours) | `24` | How long searches use the stored list |

PokeAPI itself needs no key, so the settings form refuses a key while the address is still pokeapi.co, and refuses to send one over plain http. The key is bound to the mirror's host with `x-secret-egress`: even if a mirror redirects to pokeapi.co, the platform will not let the key follow.

## Privacy

No tracking. Readers' browsers contact `pokeapi.co` for card data and `raw.githubusercontent.com` for artwork and cries (PokeAPI hosts its media on GitHub). The server contacts only the PokeAPI address.

Pokémon names, artwork and cries belong to their owners; PokeAPI serves them for fan and educational use. The plugin ships none of them.
