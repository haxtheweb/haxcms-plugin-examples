# Import Markdown (core)

**Today:** core converts markdown with markdown-it in `POST /system/api/v1/actions/md-to-html` in [haxcms-nodejs](https://github.com/haxtheweb/haxcms-nodejs) (`src/systemRoutes/v1/routes/convertMdToHtml.js`), for the editor and for the site importers that read markdown sources.

**As a plugin:** implements the core contract `import.file` for `.md` and `.markdown`. A small converter (`src/nodejs/markdown.js`, mirrored by `src/php/Markdown.php`) handles headings, paragraphs, emphasis, inline code, links, autolinks, images, ordered and unordered lists (one level), blockquotes, fenced code and rules; raw HTML passes through for core to sanitize on save. A front matter `title` becomes the title. Core makes the pages by heading. Site importers that read markdown (GitHub-based sources) reach it through `ctx.contracts.call("import.file", ...)` instead of shipping their own converter.

- **Input:** `{ name, data (base64), method: site | branch | page, type, parentId }`.
- **Output:** `{ html, title? }`, or `{ error }` (empty file).
