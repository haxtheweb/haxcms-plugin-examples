# Import spreadsheets (core)

**Today:** `POST /system/api/v1/actions/import-xlsx` in [haxcms-nodejs](https://github.com/haxtheweb/haxcms-nodejs) (`src/systemRoutes/v1/routes/importXlsx.js`, with a vendored SheetJS) turns a sheet of rows into a site's items.

**As a plugin:** implements the core contract `import.file` for `.xlsx`. It reads one sheet (`input.sheet`, else the first) through `ctx.archive.read`. The header row must name `title` and `slug`; `parent` and `content` are optional. Each row becomes a page; `parent` is matched against other rows' slugs. The structure is already in the file, so it returns items directly instead of HTML (the other shape `import.file` allows). The first bad row stops the import with its row number, as core does today.

- **Input:** `{ name, data (base64), sheet?, method, type, parentId }`.
- **Output:** `{ items: [{ id, title, slug, parent, order, indent, content }] }`, or `{ error }` (missing columns, empty title or slug, duplicate slug, unknown sheet, empty file).
- **Not supported:** the older `.xls` format, which core's SheetJS path also reads.
