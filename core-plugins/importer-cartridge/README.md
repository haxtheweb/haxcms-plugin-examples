# Import from an LMS (Common Cartridge) (core)

Turns a Common Cartridge course export (`.imscc`) into a new site. Canvas, Moodle, D2L Brightspace, Blackboard and Sakai all write this format; Canvas exports are recognised by their `course_settings/` folder. Tracked in https://github.com/haxtheweb/issues/issues/3317.

- **Site name:** the uploaded file's name without its extension, as the Word import does; the course title from the manifest goes to the site description.
- **Outline:** modules become parent pages and their items the pages under them. Whatever no module holds follows: pages at the top level, then one parent page each for Assignments, Discussions, Announcements, Quizzes and Links, in the course's own order.
- **Syllabus (Canvas):** `course_settings/syllabus.html` becomes the first page.
- **Unpublished content** (Canvas `workflow_state`) is kept with `metadata.published: false`.
- **Files:** images, documents and media are returned in `files` for core to write under `files/`; Canvas `$IMS-CC-FILEBASE$` links point at them.
- **Choosing what comes over:** `input.include` lists the kinds to bring (`syllabus`, `page`, `assignment`, `discussion`, `announcement`, `quiz`, `link`); without it everything is imported. `stats.kinds` reports how many of each were found.
- **Not converted yet:** quiz questions (QTI) become a page that says how many questions were left out; LTI tool links are counted in `stats.skipped.lti` and dropped, since they only work inside the LMS they came from.
