# Import Word documents (core)

**Today:** `POST /system/api/v1/actions/import-docx` in [haxcms-nodejs](https://github.com/haxtheweb/haxcms-nodejs) (`src/systemRoutes/v1/routes/importDocx.js`) runs mammoth to turn the `.docx` into HTML, then core's shared `importHtmlToItems` (`src/siteRoutes/v1/importUtils.js`) splits it into pages.

**As a plugin:** implements the core contract `import.file` for `.docx`. It reads the document parts through `ctx.archive.read` and returns HTML: headings (Heading 1 to 6), paragraphs, bulleted and numbered lists, tables (first row as header cells), links, bold, italic, underline and strike. The Title style or the document's title property becomes the title. Core still makes the pages from the HTML, the same way for every file type.

- **Input:** `{ name, data (base64), method: site | branch | page, type, parentId }`.
- **Output:** `{ html, title? }`, or `{ error }` (not a zip, no `word/document.xml`; a `.doc` must be saved as `.docx` first).
- **Not yet:** images (core's mammoth path inlines them).
