# Page cache (core, optional)

Serves rendered pages from a per-site cache to visitors who are not signed in.

- `render.before` answers with a stored document (`ctx.respond`) when there is a fresh one. `render.after` stores it.
- Only `mode: dynamic` renders with no user, and only when no plugin set the render context's `cacheable` to `false`.
- Cleared on page saves and deletes, site saves, any plugin's settings save (`config: ["*"]`), and any plugin being enabled or disabled.
- Settings: `ttl` seconds (0 keeps pages until something changes). `pageCacheClear` empties it by hand.

## What it implements

| Kind | Name | Runs when | What this plugin does |
|---|---|---|---|
| hook | `render.before` | a page is about to be rendered (live request or static publish) | Answers an anonymous dynamic page view straight from the cache when a copy exists and is younger than the ttl setting (0 means no expiry), skipping the rest of rendering. |
| hook | `render.after` | the document is complete (stage store) | Stores the final document of an anonymous dynamic page view, in the store stage so it runs after anything that changes or signs the document; renders marked cacheable: false are skipped. |
| hook | `page.after.save` | the page was written to disk | Clears the whole cache when a page is saved, since menus and links on other pages may change too. |
| hook | `page.after.delete` | the page was deleted | Clears the whole cache when a page is deleted, so no cached page still links to it. |
| hook | `manifest.after.save` | site.json was written | Clears the whole cache when site.json is saved, because the outline and site settings appear on every page. |
| hook | `config.after.save` | configuration was written; requirements are re-evaluated after this | Clears the whole cache when any plugin's settings are saved (subscribed with config: ["*"]), since settings can change what pages look like. |
| hook | `plugin.after.enable` | enable finished | Clears the whole cache when a plugin is enabled, since it may add to every rendered page. |
| hook | `plugin.after.disable` | disable finished | Clears the whole cache when a plugin is disabled, so pages it changed are rendered again without it. |
| operation | `pageCacheClear` | `POST /x/api/v1/plugins/<id>/clear` (bearerAuth) | Empties the page cache on request and reports how many pages were dropped. |

Each code row matches a docblock (`Implements hook ...`, `Implements operation ...`) directly above the implementation in `src/nodejs` and `src/php`.
