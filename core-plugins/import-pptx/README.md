# Import PowerPoint slides (core)

**Today:** `POST /system/api/v1/actions/import-pptx` in [haxcms-nodejs](https://github.com/haxtheweb/haxcms-nodejs) (`src/systemRoutes/v1/routes/importPptx.js`) converts slides to HTML with a vendored pptx-in-html-out and then runs `importHtmlToItems` (`src/siteRoutes/v1/importUtils.js`).

**As a plugin:** implements the core contract `import.file` for `.pptx`. Slides are read in slide-number order (slide2 before slide10) through `ctx.archive.read`. Each slide becomes an h2 section: the title placeholder as the heading (or "Slide n"), the other text as nested lists by indent level. The deck's title property becomes the title. Core makes the pages (one per slide with the site method).

- **Input:** `{ name, data (base64), method: site | branch | page, type, parentId }`.
- **Output:** `{ html, title? }`, or `{ error }` (not a zip, or no slides).
- **Not yet:** speaker notes and images.
