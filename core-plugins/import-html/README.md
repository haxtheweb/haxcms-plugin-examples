# Import HTML files (core)

**Today:** `POST /system/api/v1/actions/import-html` in [haxcms-nodejs](https://github.com/haxtheweb/haxcms-nodejs) (`src/systemRoutes/v1/routes/importHtml.js`) runs `sanitizeUntrustedHtml` (`src/lib/convertUtils.js`) and then `importHtmlToItems` (`src/siteRoutes/v1/importUtils.js`) to add pages to a site.

**As a plugin:** implements the core contract `import.file` for `.html` and `.htm`. It keeps the body and drops scripts, styles, iframes, embeds, comments, inline event handlers and `javascript:` links; the `<title>` becomes the title. Core makes the pages by heading and sanitizes again when pages are saved.

`importer-html` is the other HTML plugin: it implements `import.platform` and creates a whole new site from an HTML document.

- **Input:** `{ name, data (base64), method: site | branch | page, type, parentId }`.
- **Output:** `{ html, title? }`, or `{ error }` (no content).
