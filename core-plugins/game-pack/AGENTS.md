# AGENTS.md (game-pack)

## Purpose
Groups the concept games as blocks for course sites. Declarative only.

## Rules
- Entries point at `@haxtheweb/micro-game-base` paths; do not copy the elements in.
- Every block needs its haxProperties (validated when the package is installed).

## Build, test, validate
`hax plugin validate`. Packs with no code need no tests.
