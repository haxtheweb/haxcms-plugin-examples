# Import from HAXcms (core)

**Today:** `POST /system/api/v1/site/import/:platform` in [haxcms-nodejs](https://github.com/haxtheweb/haxcms-nodejs) (`src/systemRoutes/v1/routes/imports/convertHaxcmsToSite.js`) fetches a published HAXcms site and returns its items, files and site files for `createSite`.

**As a plugin:** implements the core contract `import.platform`. From the URL the person pastes (the site root or its `site.json`) it reads `site.json`, then each page's HTML from its `location`. It lists the files pages reference (`metadata.files`) and the site's theme overrides (`theme/theme.css`, `theme/theme.html`, and `custom/build/custom.es6.js` unless it is still the boilerplate) for core to fetch. A page that cannot be read comes back empty rather than failing the import. It may fetch only the host of the URL it is given (`egress: { input: url }`); deployment host aliases (such as HAXiam's) are applied by core before the call.

- **Input:** `{ url }`.
- **Output:** `{ title, items, files: [{ path, url }] }`, or `{ error }` (no url, not a URL, site.json unreachable or without items).
