# Import PDF documents (core)

**Today:** `POST /system/api/v1/actions/import-pdf` in [haxcms-nodejs](https://github.com/haxtheweb/haxcms-nodejs) (`src/systemRoutes/v1/routes/importPdf.js`) runs `src/lib/pdfToSemanticHtml.js` (pdfjs) and then `importHtmlToItems` (`src/siteRoutes/v1/importUtils.js`) to make pages.

**As a plugin:** implements the core contract `import.file` for `.pdf`. It reads the text of each content stream (inflating FlateDecode streams), joins runs into lines, takes the most common type size as body text and up to three larger sizes as h1 to h3, and joins nearby lines into paragraphs. The document's `/Title` becomes the title. Core makes the pages from the HTML.

- **Input:** `{ name, data (base64), method: site | branch | page, type, parentId }`.
- **Output:** `{ html, title? }`, or `{ error }` (not a PDF, or no readable text).
- **Scope of this draft:** text in standard single-byte fonts, in content-stream order. CID fonts with ToUnicode maps (common in office exports) and scanned pages are not read; the real plugin would vendor pdfjs as core does.
