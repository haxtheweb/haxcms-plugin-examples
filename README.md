# haxcms-plugin-examples

Specification, JSON Schema, conformance suite and example plugins for the HAXcms plugin architecture.

The architecture decisions and their log live in https://github.com/haxtheweb/issues/issues/3176. This repository is where the contract takes concrete shape (spec documents, `plugin.yaml` schema, fixtures, examples) so it can be reviewed before it is integrated into haxcms-nodejs and haxcms-php.

Work lands here through pull requests for review; nothing is merged without maintainer approval.
