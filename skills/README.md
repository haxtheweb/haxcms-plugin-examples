# Skills for working on HAXcms plugins

Drafts for review. Generic: no machine paths; references are GitHub URLs. They target the spec in this repository (https://github.com/haxtheweb/haxcms-plugin-examples) and will move to wherever HAX skills are published once the topology is locked.

| Skill | Use it to |
|---|---|
| [hax-plugin-dev](hax-plugin-dev/SKILL.md) | create a plugin or add pieces to one |
| [hax-plugin-audit](hax-plugin-audit/SKILL.md) | check a plugin still works, is safe and follows the pillars (read-only) |
| [hax-plugin-upgrade](hax-plugin-upgrade/SKILL.md) | move a plugin to a newer spec or HAXcms version with tests proving nothing broke |
| [hax-plugin-port](hax-plugin-port/SKILL.md) | turn a core HAXcms feature, or a WordPress or Drupal plugin, into a HAX plugin |
