# AGENTS.md (example plugin)

- This plugin is a teaching fixture, not shipped functionality. Keep it small and obviously fake.
- Tags must start with `awesome-`. Never add tracking, egress or secrets outside the settings form.
- When a hook or extension point is added to the spec, implement it here (both runtimes) in the same change.
- Run `node scripts/validate.mjs examples/example` and `npm test` from the repo root before finishing.
